# Forbes TOP30 Veri Analiz Menü Sistemi

**Proje Konusu:** Kullanıcı, menüler aracılığıyla Dünyanın En Zengin İnsanları bilgilerini listeleyebilir, güncelleyebilir ya da silebilir. Ayrıca çeşitli istatistik verilerine ve aramayı yaptığı zamanın güncel tarih-saat bilgisine ulaşabilir.

> [!CAUTION]
> **Not:** Kullanılan API, hizmetten kaldırıldığı için yerel olarak bir txt dosyasına bilgiler yüklenmiştir. Klasör içinde mevcuttur.


**Dönen Verilerden Kullanılanlar:** 7 adet veri kullanılmıştır:

•  position --> Kişinin listede kaçıncı sırada olduğu
•  finalWorth --> Kişinin o anki serveti
•  personName --> Kişinin adı, soyadı
•  source --> Kişinin servetini kazandığı şirket/şirketler
•  industries --> Kişinin servetini kazandığı endüstri
•  countryOfCitizenship --> Kişinin hangi ülke vatandaşı olduğu
•  gender --> Kişinin cinsiyeti

# Forbes TOP30 Data Analysis Menu System

**Project Description:** Through interactive menus, the user can list, update, or delete information about the World's Richest People. Additionally, users can access various statistical data and the current date and time of the search query.

> [!CAUTION]
> **Note:** Since the API used in this project has been deprecated, the dataset has been saved locally to a txt file. It is available in the repository folder.


 **Used Fields from Returned Data:** 7 fields of data from the returned response were used:

•  position --> The person's rank on the list
•  finalWorth --> The person's current net worth
•  personName --> The person's full name
•  source -->  The company/companies behind the person's wealth
•  industries -->  The industry of the person's wealth source
•  countryOfCitizenship --> The country of citizenship of the person
•  gender --> The person's gender


### How to Run

* *1. Clone or download this repository.* *
* *2. Ensure that `ForbesDataAnalyzer.java` and `forbes30.txt` are located in the same directory.* *
* *3. Compile and run the project.* *
